# tgPROXXY — сайт со списком прокси

Статический сайт: показывает свежие MTProto-прокси для Telegram, с поиском,
фильтром по стране и подключением в один клик. Без бэкенда.

```
index.html            страница
assets/style.css      оформление
assets/app.js         логика (фильтры, рендер, живое обновление)
data/proxies.json     сохранённый снимок списка (обновляется по расписанию)
tools/refresh.py      пересобирает data/proxies.json
.github/workflows/    автообновление раз в час (GitHub Actions)
serve.bat             локальный предпросмотр
```

## Как посмотреть локально

Двойной клик по `serve.bat` (нужен Python) или любой статический сервер:

```
python -m http.server 8080
```

Открыть `http://localhost:8080`.

Через `file://` сайт тоже откроется, но кнопка «Обновить» не сможет скачать
данные из-за ограничений браузера — используйте сервер.

## Как опубликовать (бесплатно)

### GitHub Pages — с автообновлением раз в час

1. Создайте репозиторий, например `tgproxxy-site`.
2. Загрузите туда **содержимое этой папки** (не саму папку), включая скрытую
   папку `.github`.
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет на `https://<логин>.github.io/tgproxxy-site/`.
5. Вкладка **Actions** → workflow «Update proxy list» уже включён: раз в час он
   пересобирает `data/proxies.json` и коммитит изменения. Первый запуск можно
   сделать руками: **Actions → Update proxy list → Run workflow**.

Git в консоли:

```
git init
git add .
git commit -m "tgPROXXY site"
git branch -M main
git remote add origin https://github.com/<логин>/tgproxxy-site.git
git push -u origin main
```

### Варианты без GitHub

- **Netlify Drop** (`app.netlify.com/drop`) — перетащить папку, получить ссылку.
  Автообновления не будет, но кнопка «Обновить» на сайте тянет свежие данные
  прямо в браузере.
- **Cloudflare Pages**, **Vercel**, любой хостинг статики — аналогично.
- Свой сервер: положить папку в `nginx`/`caddy`, добавить cron
  `python tools/refresh.py` раз в час.

## Обновить снимок данных вручную

```
python tools/refresh.py --limit 60
```

Скрипт берёт два источника, оставляет только `faketls` с uptime ≥ 95%,
которые есть в обоих списках, убирает дубли по подсетям /24 и именам хостов,
пишет `data/proxies.json`.

## Как работает обновление на сайте

- При загрузке показывается сохранённый `data/proxies.json` — быстро и работает,
  даже если GitHub недоступен.
- Кнопка **«Обновить»** скачивает оба источника прямо в браузере и пересобирает
  список на месте. Это не требует ни сервера, ни CI.

## Приватность

Сайт не отправляет данные на наши серверы (их нет): вся логика — в браузере,
запросы идут только к `raw.githubusercontent.com`. Никакой аналитики и куки.

## Оговорки

- Прокси публичные: владелец видит IP и факт подключения. Для чувствительных
  аккаунтов — свой прокси или VPN.
- MTProto-прокси работает только с Telegram, остальной трафик идёт напрямую.
- Список может устареть между обновлениями; если прокси не подключается —
  берите следующий.
